# Credit-Card-CustomerAnalytics

Interactive Looker Studio Dashboard and Python EDA analyzing Indian credit card spending habits.

## Project Overview

This project analyzes credit card spending data to understand customer spending patterns across different card types, expense categories, cities, gender, and time.

## Tools Used

1. Python
2. Pandas
3. Google Looker Studio
4. CSV Dataset

## Dashboard Overview

### 1. Overview

The Overview page provides a summary of credit card spending through the following visualizations:

1. Total Amount: Displays the overall spending amount of approximately 4.1B.
2. Record Count: Displays a total of 26,052 records.
3. Card Type Distribution: Shows the spending distribution across four card types:
   1. Silver – 26.2%
   2. Signature – 24.9%
   3. Platinum – 24.7%
   4. Gold – 24.2%
4. Spending Trend: Displays changes in spending amount over time (2013–2015).
5. Gender-wise Spending: Compares spending across female and male customers for different card types.
6. Category-wise Spending: Compares spending across Bills, Food, Fuel, Entertainment, Grocery, and Travel.

### 2. Detailed Analysis

The Detailed Analysis page provides further insights through:

1. City-wise Spending: Compares spending across different cities and card types.
2. Category-wise Spending: Shows the spending amount across different expense categories.
3. Gender Filter: Allows users to filter the analysis by gender.
4. Expense Type Analysis: Examines the relationship between record count and spending amount across expense types.

## Key Business Questions

1. What is the overall credit card spending amount and total number of records?
2. How is spending distributed across different credit card types?
3. How does credit card spending change over time?
4. How does spending compare between female and male customers?
5. Which expense categories account for higher spending?
6. How does spending vary across different cities and card types?
7. What is the relationship between record count and spending amount across expense types?
