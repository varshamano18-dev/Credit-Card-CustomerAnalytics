# Credit-Card-CustomerAnalytics
Interactive Looker studio Dashboard and Python EDA analyzing Indian Credit card spending habits.
Project Overview
This project analyzes credit card spending data to understand customer spending patterns across different card types, expense categories, cities, gender, and time.
Tools Used
. Python

. Pandas

. Google Looker Studio

. CSV Dataset

Dashboard Overview
1. Overview
 The Overview page provides a summary of credit card spending through the following visualizations:
Total Amount: Displays the overall spending amount of approximately 4.1B.

Record Count: Displays a total of 26,052 records.

Card Type Distribution: Shows the spending distribution across four card types:

Silver – 26.2%

Signature – 24.9%

Platinum – 24.7%

Gold – 24.2%

Spending Trend: Displays changes in spending amount over time (2013–2015).

Gender-wise Spending: Compares spending across Female and Male customers for different card types.

Category-wise Spending: Compares spending across Bills, Food, Fuel, Entertainment, Grocery, and Travel.

2. Detailed Analysis

The Detailed Analysis page provides further insights through:

City-wise Spending: Compares spending amounts across different cities and card types.

Category-wise Amount Analysis: Shows spending amounts across different expense categories.

Gender Filter: Allows users to filter the report based on gender.

Expense Type Analysis: Uses a scatter chart to compare record count and spending amount across expense types.
Key Business Questions

What is the overall credit card spending amount and total record count?

How is spending distributed across different card types?

Which expense categories have higher and lower spending amounts?

How does spending differ between male and female customers?

How does spending change over time?

How does spending vary across cities and card types?

What is the relationship between record count and spending amount across expense types?
